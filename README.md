# デスクトップマスコットアプリケーション「如何か(Ikagaka)」

## 概要
- デスクトップ上にキャラクターを表示するマスコットアプリケーションです。  
- キャラクターをドラッグして移動させたり、ウィンドウやタスクバーの上に座らせることができます。
---
## 作成目的
- Java言語によるプログラミングの勉強目的。
---

# 使用技術

- 言語：Java
- GUI：Java Swing
- XML処理：JAXB
- OS連携：Windows API（Win32）

---

# 主な機能

- キャラクターを画面上に表示
- キャラクターをドラッグして移動
- 一定時間ごとにキャラクターがランダムに会話
- タスクバーやウィンドウ上部に座る機能

### 右クリックメニュー

- 会話頻度変更
- キャラクター追加
- キャラクター変更
- キャラクター削除

---

# 技術的なポイント

## Win32 APIを利用したウィンドウ情報取得

Win32 APIを使用して現在表示されているウィンドウの位置やサイズを取得し、  
キャラクターをタスクバーやウィンドウの上部に配置する機能を実装しました。

---

## 透過ウィンドウによるキャラクター表示

Java Swingで背景透過のウィンドウを作成し、  
キャラクター画像のみを画面上に表示する仕組みを実装しました。

---

## キャラクターの追加

`Character` フォルダを読み込み、フォルダを追加するだけで  
新しいキャラクターを追加できる設計にしています。

キャラクター情報はXMLで定義し、  
JAXBを利用してXMLからJavaクラスへマッピングして読み込んでいます。

---

# 苦労したポイント

## キャラクター追加機能

キャラクターを追加できる拡張機能の作成に苦労しました。

`Character` フォルダ内の各キャラクターごとにまとめられた

- キャラクター画像
- キャラクター情報(XML)

を読み取り、キャラクターを自動生成する処理を実装しました。

XMLは **JAXB** を利用してJavaクラスへマッピングしています。

---

## コードの責務の細分化

キャラクターやJava Swingのコードが肥大化して可読性が低下しました。  
メンテナンスを行いやすくするためコードを分割しました。
これによりコードの保守性と可読性を改善しました。

---

## 複数キャラクターの表示と管理

複数のキャラクターを同時に表示するため、  
それぞれの

- 位置
- 会話タイマー
- 追加・削除

を個別に管理する必要がありました。

キャラクターを Listで管理し、更新処理で各キャラクターの状態を  
独立して制御できるようにしました。

---

## Win32 APIの利用

キャラクターをウィンドウの上部やタスクバーに座らせる機能を実装するため、  
全てのウィンドウの位置とサイズを取得する必要がありました。

Java標準APIでは取得できないため、  
外部APIである **Win32 API** を利用してウィンドウ情報を取得する処理を実装しました。

JavaからネイティブAPIを扱う必要があり、参考資料も少なかったため  
実装には苦労しました。
